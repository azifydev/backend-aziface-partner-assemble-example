# Assemble

**Backend Aziface Partner** - Backend de exemplo para simular a integração do parceiro com ASSEMBLE.

## � Início Rápido

```bash
# Instalar dependências
$ pnpm install

# Executar em modo desenvolvimento
$ pnpm run start:dev

# Acessar documentação da API
$ open http://localhost:60000/api-docs
```

## ⚡ Descrição

API desenvolvida para servir de exemplo como o parceiro pode integrar seu backend com o sistema ASSEMBLE para os serviços de biometria.

## 🛠️ Tecnologias Principais

- **Framework**: NestJS + Express
- **Linguagem**: TypeScript
- **Banco de Dados**: Prisma ORM
- **Documentação**: Swagger/OpenAPI
- **Autenticação**: JWT + API Keys
- **Qualidade**: ESLint
- **Deploy**: PM2
